This is an Illustrator script that fits the pattern repeat origin to the top left or centre of the target object and resets the applied transformation.

Installation method:

    1. Download the file and extract it.
    2. Copy '.jsx' to the appropriate location.
Note: The location varies depending on the version of Illustrator you are using.
3. Restart Illustrator.
4. If 'File > Scripts > ' is displayed, the installation was successful.

    *(ver)* indicates the version of Illustrator being used.
This script has not been verified for CS4 and earlier versions.

How to use:

    Select the objects to be processed (multiple selection possible).
Select File > Scripts > Reset Pattern.
Select the elements to be reset in the [Target] field.
Select Alignament:
Top Left / Top Center / Top Right
Mid Left / Mid Center / Mid Right
Bottom Left / Bottom Center / Bottom Right

Click [Do].
The pattern start point is moved according to the specified options. All effects applied to the pattern, such as scaling, rotation, shear and reflection, are reset in the process.

Repeat the starting point
Repeat the starting point

Select either 'Align to the top left corner' or 'Align to the centre of the object' to specify the pattern's repeat origin. If you do not select either option and click 'Execute', the pattern will fit to the window ruler's origin.
Advantages:

You can avoid the pattern starting in an awkward position. It is also useful when you want to align the pattern neatly in all four directions.
Processing groups

Grouped objects are based on the position and size of the top-level group, so you can align the patterns of all the objects in the group.
Disclaimer

    If you apply the effects of scaling, rotating, shearing and reflecting to a pattern without using the Appearance panel, these effects will be reset.
- Text, symbols and compound shapes are not affected.
- If there are multiple fill and line appearances, only the currently active one will be affected.
- If the group has a complex hierarchy, the result may be unexpected.
